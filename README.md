# Pre-Entrega

Tienda de Vinilos, Discos, Instrumentos, Coleccionables

Repositorio de Oido Loco, una tienda web responsiva dedicada a la industria musical.
Pre-entrega Talento Tech

## Propósito
El objetivo es ofrecer un catálogo visual e interactivo de productos musicales destacados y un formulario de contacto para consultas.

## Herramientas

- HTML5: Estructurado con `header`, `nav`, `main`, `section` y `footer`.
- CSS3
  - Flexbox: Distribución responsiva para el header, menú y la sección de productos destacados.
  - Media Queries: Adaptabilidad para pantallas móviles y de escritorio.
  - Google Fonts: Tipografía importada (`Bebas Neue`).
  - Git y GitHub: Control de versiones y repositorio del proyecto.
