# Pre-Entrega

Tienda de Vinilos, Discos, Intrumentos, Coleccionables 

Repositorio de "nombre", una tienda web responsiva dedicada a la industria musical
Pr entrega Talento Tech

#proposito
El objetivo es ofrecer un catalogo visual e interactivo de productos musicales, con reseñas, contenido multimedia y formulario de contacto para consultas y mantenimiento.

#Herramientas 

  HTML5: Estructurado con 'header', 'nav', 'main', 'section', y 'footer'
  CSS3: 
    Flexbox: Distribucion responsiva para la seccion de productos
    CSS Grid: Organizacion visual de la seccion de reseñas de clientes 
    Media Queries: Adaptabilidad para pantalla moviles y escritorio. 
    Google Fonts: Tipografia importada
  Multimedia: Integracion de reproductores y videos mediante 'iframe' 
  Formspree: Procesamiento del formulario de contacto para encargos, consultas y mantenimiento
  Git y Github: Control de versiones y despliegue del proyecto
